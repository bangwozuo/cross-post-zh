## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | string | ✅ | 待处理的原始内容 |
| `target` | string | ✅ | 需要校验的对象 |

## 输出规格

改写与适配

- `adapted`：改写后的完整文本
- `changes`：逐条说明改了什么、为什么
- `constraints`：字数/标签数等硬约束的达标情况与依据

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "content": "各位用户请注意：本店新品便携保温杯已于本月正式上架。该产品容量为500毫升，内胆采用316不锈钢材质，保温时长可达6小时。产品现售价89元，购买页面可领取10元优惠券，数量有限，售完即止。如有需要，请前往店铺选购。",
  "target": "改写为小红书口语化风格，正文控制在120字以内，结尾引导评论区互动",
  "platform": "小红书"
}

```

**输出**：

```markdown
## 改写结果

新买的保温杯真香！500ml刚刚好塞进包里，316不锈钢内胆，早上倒的热水到下午还是温的☕ 89元还能领10元券，通勤党快冲！你们秋冬天一天要喝几杯水？评论区聊聊～

（AI 生成内容，发布前需人工确认）

## 改动说明

| # | 原文要点 | 改动后 | 改动理由 |
|---|---|---|---|
| 1 | "各位用户请注意：本店新品……正式上架"公告式开头 | "新买的保温杯真香！"第一人称感叹开头 | 小红书社区语境偏好个人分享视角，公告腔会被识别为广告 |
| 2 | "该产品容量为500毫升，内胆采用316不锈钢材质，保温时长可达6小时"参数罗列 | "500ml刚刚好塞进包里，316不锈钢内胆，早上倒的热水到下午还是温的" | 把参数转为使用场景，容量/材质/保温时长三项事实全部保留，未新增 |
| 3 | "产品现售价89元，购买页面可领取10元优惠券，数量有限，售完即止" | "89元还能领10元券，通勤党快冲！" | 保留价格与优惠券两项事实；删去"数量有限、售完即止"的制造紧迫感表述 |
| 4 | 无结尾互动 | "你们秋冬天一天要喝几杯水？评论区聊聊～" | 小红书惯例以提问收尾引导评论，属于自然互动引导，非诱导好评 |

## 约束核对

1. 字数：正文约88字，满足 target"120字以内"的要求
2. 禁用词核对：未出现"最好""第一""100%"等《广告法》极限词
3. 事实一致性：500ml、316不锈钢、6小时保温、89元、10元券均来自原文，无编造、无删漏关键事实
4. 合规标识：已标注「AI 生成内容」，保留人工确认环节


```
