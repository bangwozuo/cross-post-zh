# 发布日历生成

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_05_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 分发改写师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（4 私域内容日历同构） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

跨平台发布排期与状态核对

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `items` | array | ✅ | 待处理的条目列表 |

## 输出规格

排期与调度

- `schedule`：逐项时间安排
- `conflicts`：时间/资源冲突及处理方式
- `unscheduled`：受约束无法安排的条目

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "items": "1. 小红书笔记《500ml便携保温杯开箱种草》，优先级高，要求10月13日（周二）晚间发布；2. 抖音短视频《保温杯6小时保温实测》，优先级高，要求10月13日（周二）晚间发布；3. 公众号图文《秋冬通勤水杯怎么选》，优先级中，要求10月14日至10月16日之间任意一天发布；4. 小红书笔记《办公室喝水小妙招》，优先级低，要求必须在10月13日当天发布",
  "constraints": "可用发布时段：工作日12:00-13:00、20:00-22:00；小红书每天至多发布1篇；10月12日（周一）全天不可用"
}

```

**输出**：

```markdown
## 排期表

| 日期 | 时间 | 内容 | 平台 | 状态 |
|---|---|---|---|---|
| 2026-10-13（周二） | 20:30 | 《500ml便携保温杯开箱种草》 | 小红书 | 已排期（高优先级，占用当日小红书唯一发布名额） |
| 2026-10-13（周二） | 21:30 | 《保温杯6小时保温实测》 | 抖音 | 已排期（与上条同时段，平台不同，错峰1小时） |
| 2026-10-14（周三） | 12:30 | 《秋冬通勤水杯怎么选》 | 公众号 | 已排期（落在10月14-16日要求区间内，取午间时段） |
| — | — | 《办公室喝水小妙招》 | 小红书 | 未能排入（原因见下） |

## 冲突与处理

1. 条目1（小红书）与条目2（抖音）均要求10月13日晚间发布：二者平台不同，仅发布时段重叠，无名额冲突；处理为错峰安排（20:30 与 21:30），均满足"晚间"要求。
2. 条目4（小红书《办公室喝水小妙招》）与条目1同为小红书且都要求10月13日发布，违反"小红书每天至多发布1篇"；条目4优先级低于条目1，不挤占其名额，处理为不排入10月13日。
3. 10月12日为不可用日，全部条目均未安排在该日，符合约束。

## 未能排入

1. 《办公室喝水小妙招》（小红书，要求10月13日当天发布）：与当日唯一小红书名额冲突（已被高优先级条目1占用）。建议：与用户确认后可改排 10月14日12:00-13:00 或 10月15日20:00-22:00；未经确认不擅自改期。

（AI 生成内容，排期执行前需人工确认）


```
