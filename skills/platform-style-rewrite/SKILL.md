# 平台风格改写

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_05_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 分发改写师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（改写引擎可被 4 私域文案复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

同一内容按平台语境重写

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | string | ✅ | 待处理的原始内容 |
| `target` | string | ✅ | 需要校验的对象 |

## 输出规格

改写与适配

- `adapted`：改写后的完整文本
- `changes`：逐条说明改了什么、为什么
- `constraints`：字数/标签数等硬约束的达标情况与依据

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "content": "秋冬季通勤路上，一杯合适的热饮能明显提升幸福感。我们实测了市面上5款主流便携保温杯，从容量、保温时长、重量、清洗难度四个维度逐一对比。其中500毫升档位的产品在容量与便携之间达到了较好的平衡，316不锈钢内胆的款式保温表现普遍在6小时左右。购买时建议关注内胆材质与杯口设计，杯口过小会影响清洗。",
  "target": "改写为抖音短视频口播文案，时长约60秒（约200字），口语化、开头要有钩子",
  "platform": "抖音"
}

```

**输出**：

```markdown
## 改写结果

冬天通勤你还端着凉掉的水？姐妹，问题真不在水，在杯子！我自费测了5款便携保温杯，只看四件事：容量、保温、重量、好不好洗。结果有点意外——500毫升这个档位，装得下又不坠包，是容量和便携的平衡点；316不锈钢内胆那几款，早上灌的热水到下午还烫嘴，实测6小时左右。最后提醒一句：杯口太小的别买，刷子伸不进去，洗两次你就想扔了。想看完整对比清单的，评论区扣"清单"！

（AI 生成内容，发布前需人工确认）

## 改动说明

| # | 原文要点 | 改动后 | 改动理由 |
|---|---|---|---|
| 1 | "一杯合适的热饮能明显提升幸福感"平铺导入 | "冬天通勤你还端着凉掉的水？问题真不在水，在杯子！"痛点反问开场 | 抖音前3秒需要钩子，用痛点反问替代背景铺垫，未新增事实 |
| 2 | "我们实测了5款主流便携保温杯" | "我自费测了5款便携保温杯" | 改为口播第一人称，"自费"由"实测"语境引出以增强可信度，测试对象与数量不变 |
| 3 | "从容量、保温时长、重量、清洗难度四个维度逐一对比" | "只看四件事：容量、保温、重量、好不好洗" | 书面列举改口播短句，四维度内容不变 |
| 4 | "500毫升档位……达到较好的平衡；316不锈钢内胆……普遍在6小时左右" | "500毫升这个档位……平衡点；316不锈钢内胆那几款……实测6小时左右" | 结论表述口语化，数据（500ml/316/6小时）原样保留 |
| 5 | "购买时建议关注内胆材质与杯口设计，杯口过小会影响清洗" | "杯口太小的别买，刷子伸不进去" | 选购建议改为直接口播指令，事实依据不变 |
| 6 | 无结尾互动 | "评论区扣'清单'" | 抖音惯例用评论指令提升互动，属正常引导，非诱导好评 |

## 约束核对

1. 时长/字数：全文约190字，符合"60秒（约200字）"的口播篇幅要求
2. 禁用词核对：未出现"最好""第一""100%"等极限词
3. 事实一致性：5款、四维度、500ml、316内胆、6小时、杯口清洗问题均来自原文，无新增测评数据
4. 合规标识：已标注「AI 生成内容」，保留人工确认环节


```
